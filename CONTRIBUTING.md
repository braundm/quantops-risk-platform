# Contributing

QuantOps is currently built milestone by milestone against its project specification. Before opening a change:

1. read `AGENTS.md` and the relevant methodology/architecture documents;
2. keep the domain and risk packages framework-independent;
3. add tests for behavioral and numerical changes;
4. run the narrowest relevant checks plus root lint/type checks;
5. update factual progress/evidence documentation without making aspirational claims.

Use conventional commit messages. Never include real secrets, proprietary market data, copyrighted news archives, generated dependency folders, or large model artifacts.
